Audiobestanden op de juiste plek?

Deze pagina moet naast index.html staan, met daarnaast een map audio/ZombieRun/… met jouw eigen bestanden (zelfde structuur als beschreven onder Instellingen → 🧟 Zombie Run — help in de app zelf). Open deze pagina via een lokale server (bv. python3 -m http.server in die map, dan naar http://localhost:8000/zombie_test_console.html) — rechtstreeks vanaf schijf openen (file://…) werkt niet voor het ophalen van audio.
